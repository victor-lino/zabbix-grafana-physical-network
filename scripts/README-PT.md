\# 🛠️ Scripts e Utilitários de Automação



\[\[🇺🇸 English](README.md)] | \[🇧🇷 Português](README-PT.md)



Esta pasta armazena scripts úteis e comandos de diagnóstico usados para testar, validar e manter o ambiente do laboratório de monitoramento.



\## 📁 Scripts Disponíveis



\* \*\*`network-health-check.sh`\*\*: Um script Bash para verificar a conectividade ICMP (ping) entre hosts de redes físicas e virtuais.

\* \*\*`check-zabbix-agent.ps1`\*\*: Um script em PowerShell para endpoints Windows para verificar e reiniciar rapidamente o serviço do Zabbix Agent.
