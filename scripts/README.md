# 🛠️ Scripts & Automation Utilities

[🇺🇸 English](README.md) | [🇧🇷 Português](README-PT.md)

This folder contains useful scripts and diagnostic commands used to test, validate, and maintain the monitoring laboratory environment.

## 📁 Available Scripts

* **`network-health-check.sh`**: A Bash script to verify ICMP connectivity (ping) across physical and virtual network hosts.
* **`check-zabbix-agent.ps1`**: A PowerShell script for Windows endpoints to quickly verify and restart the Zabbix Agent service.
